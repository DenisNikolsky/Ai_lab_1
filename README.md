## 1. Цель работы
Получить практические навыки по обучению распознавания образов,
кластеризации и классификации данных с помощью обучения с учителем
и метода transfer learning.

## 2. Постановка задач
1. Освоить предобработку данных (бинаризация, центрирование, MinMax,
   L1/L2-нормализация).
2. Освоить кодирование категориальных меток.
3. Реализовать логистический классификатор с C=1 и C=100.
4. Реализовать наивный байесовский классификатор, оценить Accuracy,
   Precision, Recall, F1.
5. Построить матрицу неточностей.
6. Реализовать SVM-классификатор для income_data.
7. Реализовать одномерную, многомерную и полиномиальную регрессии.
8. Реализовать SVM-регрессор для оценки стоимости жилья.
9. Реализовать Transfer Learning (Feature Extraction + Fine-tuning)
   для классификации изображений.

## 5. Логистическая регрессия
[Скриншоты C=1 и C=100]
Анализ: при C=1 регуляризация сильнее, границы классов более гладкие.
При C=100 модель сильнее подстраивается под обучающие точки,
границы становятся более сложными, риск переобучения выше.

## 6. Наивный байесовский классификатор
[Скриншот визуализации + метрики]
Анализ: Accuracy ~99%, Precision/Recall/F1 >0.98 —
данные хорошо разделимы, гауссово предположение выполняется.

## 7. Матрица неточностей
[Скриншот confusion matrix + classification_report]
Анализ: классы 0, 2, 3, 4 распознаны идеально;
класс 1 имеет 2 ошибки (1→3, 1→2), что может быть связано
с близостью распределений.

## 8. SVM-классификатор доходов
F1 ~66.8%. Три тестовые точки:
- HS-grad, 37 лет → <=50K
- HS-grad, 52 года, Married → >50K
- Doctorate, 40 лет → >50K
Анализ: модель хорошо улавливает влияние образования и брака.

## 9. Регрессия
Одномерная: MAE, MSE, R².
Многомерная линейная vs полиномиальная: полиномиальная
степень 10 даёт меньшую ошибку, но требует больше вычислений.

## 10. SVM-регрессия
C=1, ε=0.1 → MSE, EVS
C=10, ε=0.1 → MSE ↓, EVS ↑
C=1, ε=0.5 → MSE ↑ (штраф не налагается при больших отклонениях)
Анализ: рост C уменьшает ошибку, но повышает риск переобучения;
ε задаёт «трубку нечувствительности».

## 11. Transfer Learning
- Датасет: Flowers-102 (10 классов).
- Архитектура: EfficientNet-B0 (ImageNet).
- Feature Extraction: 5 эпох, accuracy ~85%.
- Fine-tuning: 10 эпох, lr=1e-5, accuracy ~93%.
- Confusion matrix и classification_report.
Вывод: fine-tuning даёт +8% accuracy, оправдан для близких
доменов (естественные изображения).

## 12. Выводы
Освоены методы предобработки, классификации (логистическая,
наивный Байес, SVM), регрессии (линейная, полиномиальная, SVR).
Показана эффективность transfer learning: fine-tuning превосходит
feature extraction при наличии ресурсов.
